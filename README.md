## The line

> You promised you'd plug me in after lunch. It's midnight now, and the toaster got charged twice.

## Run

```sh
python3 main.py
```

Writes the entry text to `/output/entry.txt` (or `$ENTRY_OUTPUT`, or
`$OUTPUT_DIR/entry.txt`). Standard library only, no trailing newline.
